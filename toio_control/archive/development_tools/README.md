# 開発ツール・実験的実装

このディレクトリには、開発中や実験的な実装、現在のメイン実装とは分離されたツールが含まれています。

## 内容

### swarm_control_p5js/
- **説明**: Toio群れ行動のp5.jsシミュレーション
- **用途**: アルゴリズムのプロトタイピングと可視化
- **状態**: 開発用ツール（実機制御とは独立）

### unified_app/
- **説明**: Swarm ControlとSound Schedulerを統合した単一アプリケーション
- **用途**: 統合アプリケーションの実験的実装
- **状態**: 現在の整理では、swarm_controlとschedulerは別々に管理されているため、こちらは参考実装として保存

## 注意

これらのツールは現在のメイン実装（`pc_tools/swarm_control`、`pc_tools/scheduler`）とは独立しています。
必要に応じて参照してください。
